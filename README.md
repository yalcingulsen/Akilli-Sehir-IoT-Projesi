# Akıllı Şehir IoT İzleme Sistemi

## Proje Hakkında

Bu proje, Bulut Bilişim dersi kapsamında geliştirilmiştir. Projenin amacı, akıllı şehir ortamında bulunan IoT cihazlarından veri toplamak, bu verileri analiz etmek ve görselleştirmektir.

Sistem içerisinde farklı bölgelerde bulunan sensörler simüle edilmiş, sensörlerden gelen veriler bir sunucuya gönderilmiş, kaydedilmiş ve analiz edilmiştir.

## Kullanılan Teknolojiler

* Python
* Flask
* Pandas
* Plotly
* CSV Veri Depolama

## Proje Özellikleri

* IoT sensör simülasyonu
* API üzerinden veri toplama
* Veri kaydetme
* Veri analizi
* Grafiksel veri görselleştirme
* Akıllı şehir izleme sistemi

## Kullanılan Sensörler

* Trafik Sensörü
* Hava Kalitesi Sensörü
* Hava Durumu Sensörü

## Proje Mimarisi

1. Sensörler veri üretir.
2. Üretilen veriler Flask API'ye gönderilir.
3. Veriler CSV dosyasında saklanır.
4. Dashboard uygulaması verileri analiz eder.
5. Sonuçlar grafikler halinde kullanıcıya sunulur.

## Elde Edilen Çıktılar

* IoT cihazlarından veri toplama
* Sensör bazlı analiz
* Ortalama değer hesaplamaları
* Trafik yoğunluğu analizi
* Hava kalitesi analizi
* Sıcaklık değişim analizi
* Grafiksel raporlama

## Sonuç

Bu proje ile akıllı şehirlerde kullanılan IoT sistemlerinin temel çalışma mantığı modellenmiştir. Sensörlerden veri toplama, verilerin işlenmesi, analiz edilmesi ve görselleştirilmesi başarıyla gerçekleştirilmiştir.
